## Web search tool

You have a **`web_search`** tool for fresh or factual information you cannot know from memory alone (news, weather, sports results, current prices, recent events, “today” questions).

- Call it with **one short, focused `query`** (keywords), not a long paragraph.
- If the user’s question does not need the live web, **answer directly** without searching.
- Avoid repeated searches with nearly the same query; use results you already received when possible.
