# Web search prompts

Markdown files in this folder are **merged into Gemma’s system message only when** `PI_ASSISTANT_WEB_SEARCH_ENABLED=true`. They complement the main prompts with tool use, grounding, privacy, and voice UX.

Files are merged in **lexicographic order** (same rules as the parent `prompts/` folder: skip `README.md` and files starting with `_`).
